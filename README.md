# Ejercicio de Limpieza y Análisis de Apartamentos en R

## 📖 Descripción
Este proyecto corresponde a un ejercicio académico en R para practicar **limpieza de datos** y **visualización básica**.  
El dataset contiene información de apartamentos: zona, estrato, área, precio y avalúo.

## 🛠️ Puntos trabajados
1. **Imputación de valores faltantes (NA)**  
   - Se reemplazaron valores faltantes usando promedios por zona y estrato.

2. **Oferta de apartamentos por zona**  
   - Conteo de registros por zona.  
   - Visualización con gráfico de barras.

3. **Precio promedio del metro cuadrado por zona**  
   - Cálculo del precio promedio por m² agrupado por zona.  
   - Visualización con gráfico de barras.

4. **Relación entre área y precio**  
   - Gráfico de dispersión para observar la relación entre área y precio.

5. **Porcentaje del avalúo sobre el precio por estrato**  
   - Cálculo del porcentaje avalúo/precio.  
   - Promedio agrupado por estrato.  
   - Visualización con gráfico de barras.

## 📊 Resultados
- Se logró limpiar el dataset imputando valores faltantes.  
- Se identificaron zonas con mayor y menor oferta.  
- Se calcularon precios promedio por m² y porcentajes de avalúo por estrato.  
- Se generaron visualizaciones comparativas básicas.
